⚽ Road to Glory

Simulador de carreira de jogador de futebol.

🎮 Sobre

Crie seu jogador, entre na base, evolua seus atributos, dispute partidas, receba propostas, mude de clube e construa sua carreira até a aposentadoria.

🚀 Projeto

- Carreira de jogador
- Sistema de evolução
- Partidas e simulação
- Transferências
- Contratos
- Notícias
- Histórico da carreira
- Sistema de temporadas
- Compatível com celular e PC

📱 Plataforma

Web — funciona diretamente pelo navegador.
